## Approve as a different operator

```bash
curl -sS -X POST https://ledger.mavula.io/api/account-lifecycle-requests/REQUEST_ID/approve \
  -H "Authorization: Bearer $CHECKER_TOKEN" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: a65e192f-aa5f-4dc9-a111-baf6136595a0' \
  -d '{"reason":"Evidence reviewed"}'
```

<Aside type="caution" title="Self-approval is rejected">
The maker and checker must be distinct effective operators. A `403` is returned when the submitting principal attempts to approve its own request.
</Aside>

## Failure handling

| HTTP status | Meaning | Resolution |
| --- | --- | --- |
| `400` | Invalid transition or malformed body | Validate transition and reason |
| `403` | Missing permission or self-approval | Use a distinct checker with `finance.approve` |
| `404` | Account or request not found in the tenant | Verify identifiers and tenant context |
| `409` | Idempotency or state conflict | Reuse the key only for an identical retry; refresh current state |
