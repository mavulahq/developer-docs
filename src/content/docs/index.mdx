## One platform, explicit ownership

| Surface | Use it for | Contract owner |
| --- | --- | --- |
| **Identity Access** | OAuth 2.0, OpenID Connect and effective operator identity | `mavulahq/identity-access` |
| **Ledger Core** | Accounts, maker-checker controls, financial configuration and projections | `mavulahq/ledger-core` |
| **Workbench** | Payment jobs, operational status and legacy batch orchestration | `mavulahq/workbench` |

All examples target API v1. Internal callbacks, health probes and observability endpoints are intentionally excluded from the public reference.
